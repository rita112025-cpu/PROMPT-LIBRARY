# PROMPT-LIBRARY ✨📝

> 靈感一鍵套用，閃光燈辣妹大片直出。Y2K + 英文潤飾，複製即用。

一個單檔就能跑的 Prompt 工具箱，專為創作者設計。內建 Y2K 豪車寫真 Prompt + 7 種英文潤飾 Prompt，24px 加粗大字，遠距清晰，一鍵複製。

**🔗 Live Demo:** https://rita112025-cpu.github.io/PROMPT-LIBRARY/

---

### ✨ Features

- **Y2K PROMPTS (5組)**：臉部鎖定 / 姿態表情 / 右手相機細節 / 冰霜妝容 / 香檳亮片掛脖
- **ENGLISH PROMPTS (7種)**：Formal / Quick Fix / Native / Clear / Perfect Grammar / Warm Pro / Concise
- **超大字設計**：Prompt 本體 24px 加粗，行距 1.7，手機電腦都好讀
- **一排式操作**：Y2K / ENGLISH 切換 + 搜尋 + 一鍵複製全部，同在一排不占空間
- **單檔部署**：無需 build，純 HTML + Tailwind CDN + Google Fonts
- **一鍵複製**：支援英文完整版 / 中文版 / 即夢版分段複製

### 🚀 Quick Start

#### 方法一：直接用 GitHub Pages (推薦)
1. Fork 或 Clone 這個 Repo
2. 確保根目錄有 `index.html`
3. 到 `Settings → Pages → Branch 選 main / root → Save`
4. 等 1-2 分鐘，網站就會在 `https://你的帳號.github.io/PROMPT-LIBRARY/` 上線

#### 方法二：本地打開
直接雙擊 `index.html` 就能用，不需要裝任何東西。

### ✍️ English Prompts 包含

- **專業校對型** - 論文、履歷、商業郵件最保險
- **快速除錯型** - 只抓錯字，不改語氣
- **自然母語型** - 消除中式英文，適合 IG 文案
- **清晰邏輯型** - 讓冗長段落瞬間清晰
- **完美文法型** - 高級感寫作，適合官網
- **溫暖專業型** - 客服、道歉信 EQ 拉滿
- **精簡俐落型** - 砍掉 30% 廢話，直擊重點
